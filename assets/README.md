# assets/

Place the following files in this folder:

| File            | Description                                                                  |
|-----------------|------------------------------------------------------------------------------|
| `profile.jpg`   | Your headshot photo. Square crop works best (~500×500 px). |
| `resume.pdf`    | Your downloadable resume PDF.                                                |
| `favicon.ico`   | Small icon shown in browser tab. Use [favicon.io](https://favicon.io) to generate. |
| `og-preview.png`| Social media preview image (1200×630 px recommended).                       |

All of these are referenced in `index.html` and must be present before deploying.
